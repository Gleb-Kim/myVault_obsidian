
1) Установи плагин
2) `ssh-keygen -t ed25519 -C "твоя_почта_на_github"`
3) `Get-Service ssh-agent`
4) `Set-Service ssh-agent -StartupType Automatic`
5) `Start-Service ssh-agent`
6) `ssh-add C:\Users\kimgl\.ssh\id_ed25519/.ssh/id_ed25519`
7) `cat ~/.ssh/id_ed25519.pub`
8) Add SSH key in github
9) `ssh -T git@github.com`
10) в .gitignore прописать:
```
# Игнорировать настройки Obsidian
.obsidian/
```
11)
```
git init
git add .
git commit -m "my obsidian vault first commit"
git branch -M main
git remote add origin git@github.com:Gleb-Kim/myVault_obsidian.git
git push -u origin main
```
12) в плагине прописать url `git@github.com:Gleb-Kim/myVault_obsidian.git`
